Переписка для макета

Соберите диалог: сообщения оппонента и свои, опционально закреп (макет iPhone).

Вход

Включён режим AUTH_ENABLED. Нужен бот и домен в BotFather для виджета Telegram.

Настройки чата

PNG скрина чата (как с телефона)

Сообщения в ленте

Порядок строк = порядок в чате сверху вниз. Можно чередовать текст и фото как угодно: нажимайте + Картинка для каждого нового медиа в переписке (сколько угодно). В любой строке тип можно сменить на «Дата» — разделитель по центру ленты.
